# SalesTrack Production System

## Production modules
- Authentication and user roles
- Super Admin dashboard
- Branch management
- Employee management
- Monthly target allocation by working days
- Daily sales and returns
- Reports
- PostgreSQL schema and RLS foundation

## Setup
1. Create a Supabase project.
2. Run `supabase/schema.sql`.
3. Configure `.env.local`.
4. Run `npm install`.
5. Run `npm run dev`.

The application contains a complete UI prototype and database-ready architecture.
